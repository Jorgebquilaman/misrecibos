# Documentación del Portal del Empleado IUPA

Bienvenido a la documentación del **Portal del Empleado IUPA**, el sistema que reemplaza al
antiguo *MisRecibos*. Acá vas a encontrar guías simples y paso a paso para instalar el
sistema y para usarlo según tu rol.

## Índice

| Guía | ¿Para quién? | ¿Qué explica? |
|---|---|---|
| [Instalación paso a paso](instalacion.md) | Quien administra servidores | Cómo compilar, configurar, desplegar y publicar el sistema |
| [Uso como Empleado](uso-empleado.md) | Todos los usuarios | Recibos, licencias, fichadas, anuncios, certificados y más |
| [Uso como Responsable](uso-responsable.md) | Jefes y directores de área | Aprobar licencias de su equipo y cargar marcas de Home Office |
| [Uso como RRHH](uso-rrhh.md) | Personal de Recursos Humanos | ABM de empleados, tipos de licencia, períodos, áreas, estadísticas y reportes |
| [Uso como Administrador](uso-administrador.md) | Administradores del sistema | Todo lo de RRHH + asignación de roles |

## Roles del sistema

Cada persona entra con su correo `@iupa.edu.ar` y tiene uno o más roles:

| Rol | Puede hacer |
|---|---|
| **Empleado** | Usar el portal como trabajador (recibos, licencias, fichadas, etc.) |
| **Home Office** | Empleado + cargar sus propios registros de ingreso/egreso manuales |
| **Responsable** | Aprobar licencias de su equipo y cargar marcas para empleados Home Office |
| **RRHH** | Administrar empleados, licencias, períodos, áreas y reportes |
| **Administrador** | Todo lo anterior + asignar roles a los empleados |
| **Dirección** | Como Responsable, con alcance institucional |

> Sugerencia: si nunca viste el sistema, empezá por
> [Uso como Empleado](uso-empleado.md). Si vas a instalarlo o publicarlo,
> empezá por [Instalación](instalacion.md).
